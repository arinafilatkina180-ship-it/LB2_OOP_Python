##### **Зміст завдань**



1\. Наслідування та поліморфізм. Створення ієрархії класів транспортних засобів із використанням базового класу та підкласів.

2\. Інкапсуляція. Реалізація класу профілю студента з публічними, захищеними та приватними атрибутами, властивостями getter і setter.

3\. Магічні методи. Створення класу двовимірного вектора з перевизначенням спеціальних методів Python.

4\. Абстрактні класи та композиція. Розробка системи доставки замовлень із використанням абстрактного класу та композиції.

5\. Патерн Strategy. Реалізація системи планування навчання з можливістю вибору та зміни алгоритму планування.



##### **Використані технології**



\- Python 3

\- Об'єктно-орієнтоване програмування

\- Стандартна бібліотека Python



##### **Запуск програм**



Для запуску кожного завдання з кореневої папки проєкту використовуйте команду:

python task2\_encapsulation/task2.py

python task3\_magic\_methods/task3.py
